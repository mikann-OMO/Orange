# 前言

又到了一年国庆，在这段富裕的时间里，最适合坐下来，好好记录一下过去的一学期。

和去年一样，我还是在不断地探索着，只是相比之前，好像又多了一些新的东西。这一年里看了很多影视作品，也在这一整个学期里尝试了许多新的软件工具，花了越来越多的时间在自己喜欢的事情上。

这一年并没有发生什么特别惊天动地的大事，更多的还是一些零零碎碎的日常。但当这些事情真正串联起来的时候，我才发现，原来自己确实已经走过了这么长的一段路。

有些事情当时看起来只不过是一次出门、一场活动、一顿饭，甚至只是一个很小的瞬间，可是过了一段时间之后，它们反而成了最容易被记住的东西。

所以还是像去年一样，把这一年的一些事情记录下来。

# 2025.11.08｜突袭合肥与同好会线下团建

其实这次去合肥也是突然决定的。当时那段时间心情一直有些闷闷的，说不上来具体是什么原因，只是觉得整个人有些沉下去，于是干脆决定出去散散心。

第一天先和老朋友出去吃了顿饭，第二天则一个人在合肥到处乱逛，也是第一次去了之心城。真正让我期待的，则是第三天第一次参加线上同好会的线下团建。

团建地点约在合肥滨湖国家森林公园。那时候天气已经入秋，温度开始慢慢降下来，我当天穿着Love Live! Sunshine!!的秋冬校服，还带了一件春秋款的黑色风衣。白天其实还算舒服，到了晚上就明显冷了起来。

早上，一部分人先去了团建发起者的家里集合。他是一位刚毕业、工作不久的大学生。看着他租着一个还算不错的房子，有着一份差不多的工作，过着自己觉得还算满意又充实的生活，我其实挺羡慕他的。

那时候的我还没有办法想象自己以后会过上怎样的生活，所以看到一个和自己年龄相仿、已经开始独立生活的人，心里难免会有一些说不出来的感觉。

我应该不是第一个到场的人，这件事情反而让我暗暗松了一口气。作为一个慢热的人，面对这种第一次参加的线下聚会，我总是会提前开始紧张：等会儿应该说些什么？我应该先开口吗？对方先开口我应该怎么回？

正当我还坐在网约车上，快到团建发起者家的小区门口时，突然发现不远处站着的人——居然是我第一次去漫展时扩列的一位小姐姐。

我还记得她当时cos的是渡边曜，还在舞台上跳了一段solo舞。那时候的她站在舞台上闪闪发光，非常有活力，也非常耀眼。

她大概已经不太记得我了，但还是很亲切地和我打了招呼。这一下倒是让我原本悬着的心稍微放下了一些。

之后又陆陆续续来了其他人。在陌生的环境里，我还是习惯性地偷偷观察着周围的人。有些人之前就已经见过面，现在很自然地聊着天，而我则站在旁边等着安排。

那种感觉其实很微妙。明明大家都是因为同一个兴趣聚到这里，却好像只有自己还隔着一层看不见的东西。

好在这种尴尬并没有持续太久，我们很快就准备出发了。

我们坐着发起者的痛车前往滨湖国家森林公园。车里装饰着不少动漫周边，而我正前方挂着的，刚好就是我喜欢的Aqours的周边。

因为自己是蹭车过去的，我还特意给发起者带了一杯卡旺卡的手剥大橘，多少算是一点小小的心意。

到了地方之后，我才发现现场原来还有其他人，其中好像是一对小情侣，那个女生我似乎在网上刷到过，出的cos非常可爱。

又过了一会儿，我在同好会里认识的第一个女生也带着她的朋友到了。

这个女孩子在我第一次去Love Live! Only 1.0的时候，给我留下了很深的印象。

那时候我刚高考结束，还是一个傻愣愣的新人，连妆都不会化。我当时在群里随口提了一嘴自己的眼妆花了，她看到之后，主动提出要借我酒精棉签帮我擦掉。

虽然那次因为她是舞者，一直到活动结束我们都没能真正见上一面，最后也没有什么更多的交集，但仅仅是这样一句主动提出的帮助，就让我觉得她是一个非常温暖的人。

而这一次，我终于真正见到了她。

她比我想象中要高一些，出的是Aqours的黑泽露比，本人的长相和她平时发在QQ空间里的cos照片几乎没有什么区别，很漂亮。

更重要的是，她整个人真的像一颗小太阳一样。刚来到我们中间，她就主动和我互动，那种自然又温暖的感觉，让我一下子放松了很多。

那一天其实是一个有些阴沉的秋日，森林公园里的植被也显得有些萧瑟。可偏偏就是在这样的环境里，一群人放着音响，一边聊天一边走在路上，散发出来的青春活力反而显得格外鲜明。

那一刻我突然觉得，这就是我一直以来所期待的那种鲜活的日常。

不是一定要发生什么特别的事情，也不需要多么宏大的目的，只是一群喜欢着相同东西的人，在一个普通的秋天聚在一起，一起走路，一起聊天，一起消磨掉一天的时间。

后来我们找了一片空地开始玩UNO，这是我第一次玩这个游戏。最开始其实还有些拘谨，但玩着玩着大家就慢慢熟悉起来，气氛也越来越轻松。

我们在那里玩了很久，天色也渐渐暗了下来。等到真正准备离开的时候，天已经完全黑了。

因为这个地方很大，又有人有些怕黑，所以大家一路上不断聊天、说笑话，努力让这段路不要显得那么漫长。直到终于走到出口，我才觉得今天的活动似乎真的结束了。

原本我已经准备离开，但可能因为交流上出了些问题，发起者又带着我和另外一个人回到了他家。我们在那里看了一会儿他买的各种周边，过了一阵子，又来了一个我之前不认识的女生。

聊了一会儿之后，我才发现原来她也是同好会群里的人，平时我与她也有过交流。

她整个人很小巧，也很可爱，第一眼就很容易让人产生一种强烈的保护欲。

当时大家准备一起下楼吃饭，我因为没有带外套，已经冻得有些发冷。她当时穿着一件白色毛茸茸的外套，发现我可能有些冷之后，突然抱住了我给我取暖。那一瞬间真的直接把我整害羞了。

她整个人毛茸茸的、暖呼呼的，还有一点淡淡的香味。我只能努力压住脑子里乱撞的思绪，整个人僵在那里。

期间我还跟她说感觉有点不适应，结果她以为自己是不是冒犯到我了。我赶紧解释并不是那个意思，只是单纯觉得有些不好意思，于是她又抱了我一会儿。后来我的外套拿来了，她才没有继续抱着我。

之后大家一起去吃了饭，吃完又继续尬聊了一会儿。其实我也不知道当时到底在聊些什么，只记得大家一直在努力寻找新的话题，让这个夜晚不要那么快结束。

等我真正离开的时候，已经差不多晚上十一点了。那时候确实已经很晚，我回到酒店之后，第二天便离开了合肥。

其实这次出行并没有真正解决我当时的烦闷。出来之前是什么心情，回去之后好像还是差不多，甚至之后又有了新的烦恼。

可是现在再回头看，我还是很庆幸自己当时突然做了这个决定。那几天并没有改变什么，却给我的生活留下了一段很特别的记忆。

# 2026.01.24｜寒假广东网友第一次来安徽

进入寒假之后，发生的第一件比较特别的事情，是一位广东网友第一次来到安徽游玩。

我们先在合肥见面，然后我再带他去了淮南。这是我认识的外地网友里，第一个在提出后真正来到安徽的网友。

只可惜他来的时候，之前的雪已经化得差不多了。如果再早几天，说不定还能看到漫天都是雪的安徽。

不过天气已经开始慢慢变暖，我觉得其实没有想象中那么冷，他却还是冷得不行，甚至还戴着骑电瓶车时候用的那种手套。

在合肥的时候，我带他吃了地锅鸡，只不过他吃不了辣，结果被辣得够呛。之后我们还逛了步行街和骆岗公园。

又来到淮南，带他吃了正宗的淮南牛肉汤和板面，还一起逛了淮南龙湖公园。

他是个挺奇怪的人，大学专业学的是心理学，但我和他接触之后，反而总觉得他好像更需要找心理医生。当然，他这个人并不坏，只是偶尔会做出一些让我完全摸不着头脑的举动，所以和他相处的时候，总会有一种很奇妙的感觉。

寒假期间，我也开始投入到飞天小女警痛车的制作当中，同时还帮之前合肥团建认识的那位女生的团做了一些有偿作图。好像不知不觉地把越来越多的时间投入到设计和制作中了。

# 大二下学期｜慢慢变得热闹起来

开学之后，生活重新回到了学校的节奏。

刚开学没多久，我就连续完成了两次非常离谱的操作——先是把一份酸辣粉撒到了自己身上，第二天出去又把一杯柠檬水撒到了自己身上。只能说，新学期从一种非常“水逆”的运气开始了。

3月14日，我和舍友一起去了南京欢乐谷，玩了不少刺激项目，整体还是非常开心的，唯一遗憾的是最后没有玩到过山车。

晚上第一次去了萨莉亚。因为之前经常看同好群里的群友去吃，一直很好奇到底是什么感觉，真正吃完之后只能说——确实还行。

开学以后，飞天小女警痛车也继续慢慢做着。与此同时，我还无偿帮忙制作了合肥Love Live! Only 2.0的宣传图和活动物料。

其实原因也很简单。这种自发组织起来、完全靠大家对作品的喜欢支撑起来的活动并不容易，既然自己刚好会做一点设计，那就想尽量出一份力。

这一学期的生活似乎也比以前丰富了不少。

我发现自己出去吃饭的次数明显变多了，自助餐、漂亮饭以及各种以前不会特意去尝试的东西，开始一点一点进入日常。与此同时，我也继续看了很多电影和影视作品，尝试新的软件和工具，慢慢学习一些以前完全不会的东西。

虽然这些事情单独拿出来看都很普通，但它们组合起来，就是这一阶段的生活。

# 2026.06.19—06.21｜苏州网友来合肥 & Love Live! Only 2.0

之前一起去过苏州的那位网友，这次来到了安徽合肥。

19号和20号，我带他去了安徽省美术馆、合肥逍遥津和合柴，还一起去了汉堡节，花了六七十块钱吃了一个很贵、但确实很好吃的汉堡。之后又去了骆岗公园。

期间他还把自己的相机借给我玩，后来我也干脆带着他的相机去了Love Live! Only 2.0。

21号，终于迎来了期待已久的合肥Love Live! Only 2.0。

陪我第一次去漫展的那位朋友，这次也陪我来了第二次漫展。

看着自己之前画出来的东西真正被制作出来，并且落地应用在活动现场，心里其实一直在偷偷窃喜。那种感觉和单纯把一张图发到网上完全不一样。

当自己亲手做出来的东西真的出现在现实里，甚至被陌生人拿在手里时，会产生一种很奇妙的成就感。

这次我没有出cos。对现在的我来说，cos还是有些太麻烦了，所以只是从外观装饰上加入了一些相关元素，再搭配了一个简单的痛包，带上一些官方物料和自己制作的东西。

本来我还以为自己这次算是staff，应该可以更有参与感一些，结果真正到了现场，却还是觉得自己好像什么忙都帮不上，甚至一度有些无地自容。

刚开始朋友还没有到，我先跟飞天小女警痛车车主的对象一起去给另一辆车量数据。他也希望我帮他做唐可可梨子的痛车设计，所以刚好约在这一天和车主、车商三个人一起把车子的尺寸量了一遍。

结果最后做完之后，因为我个人的一些原因，数据还是搞错了。只能说设计落地还是太容易出错了。

原本我还期待这次能够交换很多物料，但最后其实也没有拿到多少。活动里还是存在着很多不同的小团体，而我平时几乎没有参与二次元线下活动，所以想真正融入进去依旧有些困难。

我的朋友对这个IP的喜欢程度也没有那么浓烈，带她来这里某种程度上其实也算是一种折磨。

因此整场活动下来，我们大部分时间都是坐在那里看演出。场地本身就是live house，大家基本都是站着的，还好认识的人帮我们弄来了两张板凳，于是我们就这么坐着看了一下午。

活动现场还是很热闹的。我拿着相机拍了很多照片，也在线下见到了不少以前只在网络上认识的人。

很多时候只是简单打个照面、交换一下物料，然后又各自去做自己的事情，但对于我来说，这些原本只存在于网络上的头像突然变成了现实中的真人，依旧是一件很奇妙的事情。

我也再次见到了上次团建时认识的那些人。这种人与人之间因为同一个兴趣而不断产生交集的感觉，或许也是参加这些活动最大的意义之一。

当天还有一个特别有意思的小插曲。

场馆里总是会出现一些看起来有些奇怪的大人，我还一度喊staff出警。结果后来发现，其中一位大叔居然是老资历。

他其实是正常买票进场的，只是因为一直在后面鬼鬼祟祟地乱转，导致我误会了他。

后来我才注意到，他身上那件不起眼的T恤上印着缪斯，看起来似乎还是一件非常古早的官方T恤。

我当时觉得，他大概是只喜欢缪斯的老前辈，于是有点不好意思，就送了他一张自己做的缪斯全员贴纸物料。

他接过去之后跟我说了一句：“谢谢老师。我当场愣住。

后来他又过来跟我说：“谢谢你的物料，我现在只有笑颜老师的物料，借花献佛送给你。我又一次懵了。

好一个“借花献佛”，一听就知道绝对是老资历。

后面我还看到他跟几个小姐姐集邮，后来把这件事情说到群里，才发现他确实是个真正的老资历，而且已经四十多岁了。

现在回想起来还是觉得特别好笑。一个四十多岁的老前辈，居然被我这个死小孩误认成了奇怪的大叔。

当天晚上回到酒店的时候，刚好赶上CS2科隆Major决赛。于是这一天就在Love Live! Only 2.0和CS2科隆Major决赛的双重夹击下结束了。（尼尼孩孩major冠军）

# 2026｜暑假二三事

暑假相比前面几个月，又是另一种节奏。

8月1日是高海千歌，也就是奇卡的生日。我和朋友一起出去玩，提前定了一个奇卡头的蛋糕，还第一次玩了网上爆火已久的拼豆，真挺好玩。

那天穿着Love Live! Sunshine!!的夏季校服，抱着奇卡的一米趴在家里布置了一下拍了很多照片，晚上又一起去了必胜客，没想到在那里还遇到了高中同学，简单聊了一会儿。

没有什么特别宏大的安排，却意外地度过了非常充实的一天。而且是真的很开心。

之后8月3日到8月19日，我带着亲戚家的小孩去了浙江。

那段时间一边照顾小孩，一边继续做唐可可×樱内梨子的痛车设计。带小孩和设计两件事情就这样混在了一起，反而成了这个暑假里一段很特别的记忆。

当然，照顾小孩这件事情本身就没有那么美好了。

我也是非常直观地感受到，现在的小孩真的很容易受到网络内容的影响这件事了。他总是说一些莫名其妙、没有什么营养的话，做一些莫名其妙的举动，有时候真的让我不知道该说什么。

# 写在最后

如果一定要给这一年下一个结论，我好像还是很难说自己究竟发生了多大的变化。

我依旧是那个慢热的人，面对陌生的人群还是会紧张，还是会不知道应该说些什么，还是会搞砸很多事，还是会去体验很多事。

但我似乎已经逐渐习惯一个人去外地，也慢慢习惯了与网友见面；参加了同好会的线下活动，开始给别人制作设计，开始把自己会的一点东西拿出来帮助别人，也开始因为一个共同喜欢的作品认识越来越多的人。

这一年里，我做了很多以前没有做过的事情，也看了很多以前没有看过的东西。

有些事情很开心，有些事情很尴尬，有些事情甚至在当时并没有让我觉得有什么意义。

就像11月那次合肥之行一样，出发之前的烦闷并没有因为旅行而真正消失，回来之后，生活也还是会继续产生新的问题。

可是现在回头看，我还是觉得这些经历值得被记录下来。

因为生活本来就是由这些看起来不起眼的东西组成的。

是秋天滨湖森林公园里一群人放着音乐走在路上的声音，是第一次玩UNO时逐渐熟悉起来的感觉，是深夜里那件毛茸茸的外套，是第一次看到自己画的东西真正落地时偷偷窃喜的瞬间，是坐在活动场地里拿着相机拍照的下午，也是暑假里穿着喜欢的衣服、抱着一米趴拍照的那个夏天。

这些事情不会改变我的人生，也没有什么惊天动地的意义。但它们确实发生过。而且，它们都是属于我的。

所以到了又一年的国庆，我还是想把它们写下来。也许明年再回头看的时候，我会发现自己又走了很远。
