# 问题解答

1. Illustrator中导入了像素及分辨率足够大的图片（也就是我们所说的位图），为什么在PS中显示边缘是平滑的，到了Illustrator中显示边缘是锯齿状的呢？

- 答：看看你是否在Illustrator中给图片添加了`羽化`效果。尝试关闭这个效果，看是否能解决问题。这个或许是因为你Illustrator开的画布比较小，羽化效果跟随画布大小变化，而位图的尺寸过大导致羽化行锯齿状。

2. 为什么我用多个形状（比如两个圆）去裁切图片时，AI提示“无法建立剪切蒙版”？

- 答：因为剪切蒙版（Ctrl+7）的顶层对象必须是一个**单一的路径**（或复合路径），不能是多个独立的形状。  
  正确做法是：  
  ① 先选中所有用作裁切的形状 → 按 **Ctrl+8**（将它们合并成一个复合路径）；  
  ② 再同时选中图片和这个复合路径 → 按 **Ctrl+7**（建立剪切蒙版）。  
  这样就能顺利实现多孔或异形裁切。

3. 为什么不能用 `Ctrl+G`（编组）来代替 `Ctrl+8`（复合路径）作为剪切蒙版的顶层？

- 答：`Ctrl+G` 编组只是逻辑上的“打包”，方便管理对象，但路径算法上它们依然是多个独立的“容器”，剪切蒙版无法识别。  
  而 `Ctrl+8` 复合路径是在数学层面**真正合并**成一个单一对象，所以能被剪切蒙版接受。  
  因此，多个形状想要一起作为蒙版，必须先做复合路径（Ctrl+8），而不是编组（Ctrl+G）。

# 常用快捷键 Illustrator

## 1. 基础操作快捷键（必备入门）
与PS相似但略有不同，建议优先掌握！

| 快捷键组合 | 功能说明 | 使用备注 |
| --- | --- | --- |
| Ctrl+N | 新建文档 | 可预设画板数量、尺寸、出血等 |
| Ctrl+O | 打开文件 | 支持AI、EPS、PDF、SVG等格式 |
| Ctrl+S | 保存文档（默认AI格式） | 建议频繁保存，避免崩溃丢文件 |
| Ctrl+Shift+S | 另存为（可选格式） | 可导出为EPS、SVG、PDF等 |

| Ctrl+Z | 撤销上一步 | 仅单次撤销 |
| Ctrl+Alt+Z | 多次撤销（返回多步） | 回溯历史操作，比PS更灵活（默认支持多步） |
| Ctrl+Shift+Z | 恢复上一步撤销 | 重做操作 |
| Ctrl+R | 显示/隐藏标尺 | 辅助精准定位 |
| Ctrl++ / Ctrl+- | 放大/缩小画布 | 也可用Alt+滚轮 |

# 蒙版与复合路径详解（核心知识点）

## 1. 三种蒙版的区别与用法

| 蒙版类型 | 核心作用 | 操作入口 | 快捷键 |
| :--- | :--- | :--- | :--- |
| **剪切蒙版** | 用上层形状裁剪下层内容（显示形状范围内的部分） | 选中两个对象 → 菜单“对象” > “剪切蒙版” > “建立” | **Ctrl+7**（建立）<br>**Ctrl+Alt+7**（释放） |
| **不透明度蒙版** | 通过黑白灰度控制透明度（黑隐藏，白显示，灰半透明） | “透明度”面板中点击“制作蒙版” | 无直接快捷键（需面板操作） |
| **图层蒙版** | 类似PS，用画笔涂黑白来控制图层的可见区域 | 图层面板底部点击“建立蒙版”图标 | 无直接快捷键（需面板操作） |

> **重点**：最常用的是**剪切蒙版（Ctrl+7）**，但它的上层对象**必须是一个单一的路径**（或复合路径），不能是多个独立图形或编组。

---

## 2. 复合路径（Ctrl+8）

- **作用**：将多个独立的路径合并成一个逻辑上的**单个复合路径**，常用于制作**镂空效果**（如在一个形状上挖出文字或洞）。
- **建立**：选中多个路径 → 按 **`Ctrl+8`**
- **释放**：选中复合路径 → 按 **`Ctrl+Alt+8`**

---

## 3. 修改已建立的剪切蒙版（含复合路径）

- 选中剪切蒙版对象，使用 **`A`（直接选择工具）** 点击内部子路径（如某个小孔），即可单独拖动调整其位置或形状。
- 若调整后复合路径逻辑错乱，可重新选中整个剪切蒙版，再按一次 `Ctrl+8` 刷新。
---

## 4. 速查总结表

| 快捷键 | 功能 | 与剪切蒙版的关系 |
| :--- | :--- | :--- |
| **Ctrl+G** | 编组 | ❌ 不能用作剪切蒙版的顶层对象 |
| **Ctrl+8** | 建立复合路径 | ✅ 将多个路径合并为单一对象，可作为剪切蒙版顶层 |
| **Ctrl+7** | 建立剪切蒙版 | 依赖于顶层对象是单一路径或复合路径 |
| **Ctrl+Alt+7** | 释放剪切蒙版 | 恢复为普通对象 |
| **Ctrl+Alt+8** | 释放复合路径 | 将复合路径拆分为独立路径 |
