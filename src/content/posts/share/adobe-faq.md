# 问题解答

*注：仅个人经验，非专业解答，不全面，但或许可以解决你遇到的疑难杂症*

1. illustrator中导入了像素及分辨率足够大的图片（也就是我们所说的位图），为什么在ps中显示边缘是平滑的，到了illustrator中显示边缘是锯齿状的呢？

- 答：看看你是否在illustrator中给图片添加了`羽化`效果。尝试关闭这个效果，看是否能解决问题。这个或许是因为你illustrator开的画布比较小，羽化效果跟随画布大小变化，而位图的尺寸过大导致羽化行锯齿状。

# 常用快捷键Photoshop

## 1. 基础操作快捷键（必备入门）
快捷键是PS操作的基础，无论修图还是设计都高频使用，建议优先掌握！

| 快捷键组合 | 功能说明 | 使用备注 |
| --- | --- | --- |
| Ctrl+N | 新建画布/文档 | 新建时可直接设置尺寸、分辨率 |
| Ctrl+O | 打开图片/文档 | 支持批量选中多张图片同时打开 |
| Ctrl+S | 保存文档（默认格式） | 建议修图时频繁使用，避免文件丢失 |
| Ctrl+Shift+S | 另存为（可选格式） | 适合导出JPG、PNG、PSD等不同格式 |
| Ctrl+W | 关闭当前文档 | 按住Shift+Ctrl+W可关闭所有打开的文档 |
| Ctrl+Z | 撤销上一步操作 | 仅单次撤销，适合快速修正误操作 |
| Ctrl+Alt+Z | 多次撤销（返回多步） | 新手必备，修图时可回溯多步操作 |
| Ctrl+Shift+Z | 恢复上一步撤销 | 误撤销后快速恢复，避免重复操作 |
| Ctrl+R | 显示/隐藏标尺 | 辅助构图，搭配参考线使用更精准 |
| Ctrl++ / Ctrl+- | 放大/缩小画布 | 按Alt+鼠标滚轮也可快速缩放 |
| 空格+鼠标左键 | 拖动画布 | 放大后快速查看图片不同区域 |
| Ctrl+0 | 画布适配窗口大小 | 快速查看整张图片的整体效果 |

## 2. PS常用工具快捷键（快速切换高效）
这类快捷键可快速切换常用工具，避免反复点击工具栏，提升操作流畅度！

| 快捷键 | 对应工具 | 使用备注 |
| --- | --- | --- |
| V | 移动工具 | 默认工具，快速移动图层、选区内容 |
| B | 画笔工具 | Shift+B切换画笔/铅笔；[ ]调整画笔大小 |
| E | 橡皮擦工具 | Shift+E切换橡皮擦/背景橡皮擦/魔术橡皮擦 |
| I | 吸管工具 | 快速吸取图片中的颜色作为前景色 |
| T | 文字工具 | 点击图片即可添加文字，方便快捷 |
| J | 修补工具 | Shift+J切换修补/红眼/污点修复；可搭配内容识别使用 |
| S | 仿制图章工具 | 按住Alt取样，用于修复瑕疵、复制纹理 |
| O | 减淡/加深工具 | Shift+O切换；适合人像光影精修 |
| G | 渐变工具 | Shift+G切换渐变类型；可制作背景渐变效果 |

## 3. 画笔操作快捷键（画笔工具专属）
使用画笔、橡皮擦、仿制图章等工具时，这些快捷键能让绘制更加得心应手！

| 快捷键组合 | 功能说明 | 使用备注 |
| --- | --- | --- |
| `[` | 缩小画笔 | 逐级减小画笔直径，适合精细绘制 |
| `]` | 放大画笔 | 逐级增大画笔直径，适合大面积涂抹 |
| Shift+`[` | 减小画笔硬度 | 让画笔边缘更柔和，适合过渡涂抹 |
| Shift+`]` | 增加画笔硬度 | 让画笔边缘更清晰，适合明确边缘的绘制 |
| Alt+鼠标右键（左右拖动） | 调整画笔大小 | 按住后左右拖动可快速调整画笔直径 |
| Alt+鼠标右键（上下拖动） | 调整画笔硬度 | 按住后上下拖动可快速调整画笔硬度 |

## 4. 选区工具快捷键（精准修图核心）
选区是PS修图的基础，这类快捷键能帮你快速创建、调整选区，提升修图精准度！

| 快捷键组合 | 功能说明 | 使用备注 |
| --- | --- | --- |
| M | 切换矩形/椭圆选框工具 | Shift+M切换工具；Shift+绘制=正方形/正圆形 |
| L | 切换套索/多边形套索/磁性套索 | Shift+L切换；磁性套索适合边缘清晰的物体 |
| W | 切换快速选择/魔棒工具 | Shift+W切换；魔棒适合纯色背景选区 |
| Ctrl+Enter | 路径转选区 | 用钢笔工具绘制路径后快速转化 |
| Ctrl+D | 取消选区 | 修图完成后快速取消，避免选区干扰 |
| Shift+Ctrl+I | 反选选区 | 需要选中"除目标区域外"的区域时使用 |
| Alt+鼠标拖动选区 | 复制选区内容 | 快速复制图层中的局部元素 |
| Shift+绘制选区 | 增加选区 | 多个不连续区域需要同时选中时使用 |
| Alt+绘制选区 | 减少选区 | 剔除选区内不需要的部分 |
| Ctrl+Alt+D | 羽化选区 | 输入1-2像素可让选区边缘更柔和，避免生硬 |

## 5. 图层操作快捷键（专业修图必备）
图层是PS的核心功能，掌握这些快捷键能快速管理图层，避免破坏原图，提升修图安全性！

| 快捷键组合 | 功能说明 | 使用备注 |
| --- | --- | --- |
| Ctrl+J | 复制当前图层 | 避免直接在原图上操作 |
| Ctrl+Shift+N | 新建空白图层 | 适合添加文字、绘制图形时使用 |
| Ctrl+E | 向下合并图层 | 合并当前图层与下方图层，节省内存 |
| Ctrl+Shift+E | 合并可见图层 | 仅合并显示的图层，隐藏图层不参与 |
| Alt+鼠标点击图层间 | 创建剪贴蒙版 | 仅让上层内容作用于下层选区，精准修图 |
| Shift+Ctrl+[ | 图层移至最底层 | 快速调整图层堆叠顺序 |
| Shift+Ctrl+] | 图层移至最顶层 | 避免图层被其他元素遮挡 |
| Alt+点击图层眼睛图标 | 单独显示当前图层 | 快速查看单个图层的效果，方便排查问题 |
| Ctrl+Shift+Alt+N | 新建调整图层 | 非破坏性修图，可随时修改调整参数 |
| Alt+Delete | 填充前景色 | 在选区或图层中快速填充前景色 |
| Ctrl+Delete | 填充背景色 | 在选区或图层中快速填充背景色 |

## 6. 图像调整快捷键（调色修图核心）
这类快捷键覆盖调色、光影调整等核心需求，适合电商修图、人像精修、风景调色等场景！

| 快捷键组合 | 功能说明 | 使用备注 |
| --- | --- | --- |
| Ctrl+M | 打开曲线调整 | 精细调整亮度、对比度、色彩层次 |
| Ctrl+L | 打开色阶调整 | 快速修复过亮/过暗图片，调整明暗细节 |
| Ctrl+U | 打开色相/饱和度 | 调整颜色鲜艳度、色调，适合调色创作 |
| Shift+Ctrl+U | 去色（转为黑白） | 快速制作黑白风格图片 |
| Ctrl+Alt+Shift+B | 黑白调整 | 比去色更细腻，可调整不同颜色通道明暗 |
| Ctrl+T | 自由变换 | 缩放、旋转、扭曲元素；Shift+变换保持比例 |
| Ctrl+Shift+T | 重复上一次变换 | 批量复制并变换元素，提升效率 |
| Ctrl+Alt+T | 复制并变换 | 快速制作对称、重复的设计元素 |
| Shift+Ctrl+C | 合并拷贝 | 复制所有可见图层的合并效果，不破坏原图层 |
| Ctrl+Shift+Alt+C | 内容识别缩放 | 调整图片尺寸时保护主体不被拉伸 |
